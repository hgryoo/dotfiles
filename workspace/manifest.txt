# /data/workspace manifest — topic-centric (canonical)
#
# One axis: a topic owns its checkouts, builds and run output.
#
#   repos/<name>              an upstream clone — not owned by a topic
#   topic/<topic>/wt/<t>      a checkout for that topic
#   topic/<topic>/build/<n>   its build tree and install prefix
#   topic/<topic>/runs/<e>/<v>  what that build produced
#   harness/                  run scripts shared across topics
#   archive/                  kept but finished
#
# What this deliberately does NOT list: the per-run and per-build directories
# themselves. The previous manifest had 400 entries and 280 of them were empty
# shells of finished experiments (151 under runs/, 129 inside install
# prefixes). Their value was their contents, which no machine carries — a new
# build makes its own prefix and a new run makes its own output directory. It
# also does not list past worktrees: 20 of the 43 old entries had no citation
# anywhere in the vault, so no topic could be assigned without inventing one,
# and a finished PR's worktree is not something a fresh machine needs.
#
# Written 2026-09-18. Regenerate with --emit only from a topic-centric tree.
